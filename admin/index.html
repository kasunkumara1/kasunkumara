ONE-TIME SETUP

GitHub Pages + Admin connection

01

Create a public GitHub repositoryUpload everything from this project ZIP to the repository root.

02

Enable GitHub PagesSettings → Pages → Deploy from a branch → main → /(root).

03

Create a fine-grained access tokenLimit it to this repository and give Repository permissions → Contents → Read and write.

04

Open /admin/Enter owner, repository, branch and the token. The token stays in this browser session only.

Important

Never put your GitHub token inside HTML, JavaScript, screenshots or the repository. This admin stores it only in sessionStorage and removes it when you disconnect or close the browser session.

SECURE REPOSITORY CONNECTION

Connect your GitHub portfolio

The admin needs write access to your portfolio repository. Use a fine-grained token restricted to this repo with Contents: Read and write.

Token is kept only for this browser session. It is never committed to GitHub.
